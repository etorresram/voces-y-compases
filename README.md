# Voces y Compases (nombre por validar)

Proyecto de asociación cultural sin fines de lucro (ONG) impulsada por
Onelia Ardiles Carrasco: formación en música, canto, declamación, coros y
poesía para jóvenes de colegios nacionales, con un piloto de 6 meses.

- `index.html`: presentación interactiva y autocontenida (sin dependencias,
  salvo Google Fonts). Se abre con doble clic o se publica con GitHub Pages.
- Contenido: justificación, programa, ruta de 6 meses, organigrama, ruta de
  constitución (SUNARP, SUNAT, APCI), marco normativo, presupuesto
  referencial interactivo, indicadores, riesgos y siguientes pasos.

El documento original de la fundadora (`Formas de desarrollo de la ong.docx`)
no se versiona. La parte legal es un esquema general: verificar con notario y
contador.

## Plantillas (`plantillas/`)
Formatos en blanco, sin datos personales, para usar en el piloto:
- `Ficha_de_evaluacion_de_talentos.docx`: evaluación inicial y final de cada joven.
- `Autorizacion_madre_padre_tutor.docx`: participación, datos, imagen y salud de menores.
- `Evaluacion_del_piloto_por_el_colegio.docx`: ficha que llena el colegio al terminar el piloto.
- `Codigo_de_conducta_docentes_y_voluntarios.docx`: reglas de trato, comunicación y reporte para quienes trabajan con menores.
Revisar con un abogado antes de usar.
